# SX Anime Helper V3.7

Blender 二次元风格化渲染插件，适配 Blender 4.1 - 5.x。

由 Paper朱二次元助手 V2.0（风格色彩版）与 V3.1.0（强化版）合并而来，包含两个版本全部功能。

---

## ✨ 功能

- **一键描边**：应用 / 修复 / 撤销，粗细滑杆实时调节
- **一键二次元色彩**：色彩对比预设 + 曝光调节，可撤销
- **高光皮肤材质**：二分混合 + 高光 + 边缘光 + Matcap 质感，混合程度与粗糙度实时调节，可撤销并恢复原材质
- **单材质槽处理**：只处理选中的材质槽（自动跳过描边材质）
- **一键二次元辉光**：合成器三级 Bloom，阈值实时调节，可撤销（兼容 Blender 5 新合成器）
- 执行时自动切换 EEVEE（可关闭）

## 📦 安装方法

1. 下载 `sx-anime-helper-v3.7.zip`
2. 打开 Blender
3. 进入 **编辑 → 偏好设置 → 插件**
4. 点击 **安装**，选择该 ZIP 文件
5. 启用 **SX Anime Helper**

## 📍 面板位置

- **3D 视图 → N 面板 → SX Anime**
- 着色器编辑器 → N 面板 → SX Anime（含单材质槽子面板）
- 材质属性 → SX Anime Skin Highlight

## ⚠️ 说明

- 皮肤与描边功能依赖 EEVEE（ShaderToRGB 节点），Cycles 下不可用
- 不同模型结构、材质透明设置、法线状态可能影响描边与辉光表现，如遇异常可优先尝试"修复描边"
