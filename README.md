# 二次元助手 (Paper朱 Anime Helper)

Blender 5.0.1 二次元风格化插件

---

## ✨ 功能

- 一键添加黑色描边（Solidify + 法向翻转）
- 高光皮肤材质（Skin_shiny 风格）
- 自动忽略描边材质
- 单材质槽独立处理
- Matcap 高光支持
- 二次元色彩管理

---

## 📦 安装方法

1. 下载本仓库 ZIP
2. Blender → 编辑 → 偏好设置 → 插件
3. 点击“安装”
4. 选择下载的 ZIP
5. 启用插件

---

## 📍 面板位置

- 3D视图 → N面板 → 二次元助手
- Shader编辑器 → N面板 → 二次元助手
- 材质属性面板 → 高光皮肤材质
