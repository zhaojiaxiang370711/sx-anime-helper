# Paper朱二次元渲染助手 V2.0

Blender 5.0 二次元风格化渲染插件。适配版本4.1-5.0

---

## ✨ 功能更新

- 一键添加黑色描边（可调粗细了）
- 可选“修复描边”模式，减少描边壳层干扰
- 高光皮肤材质（可调混合程度了）
- 二次元风格化色彩管理（可调对比强度了）
- 一键二次元辉光（可调辉光阙值）

---

## 📦 安装方法

1. 下载本仓库release的 ZIP V2.0版本
2. 打开 Blender
3. 进入 **编辑 → 偏好设置 → 插件**
4. 点击 **安装**
5. 选择下载的 ZIP 文件
6. 启用插件

---

## 📍 面板位置

- **3D 视图 → N 面板 → Paper二次元渲染助手**

## 🔥 项目目标

为 Blender 中的二次元角色渲染提供更方便、更直接的风格化工具，  
用一键化方式完成描边、皮肤高光、色彩管理与辉光效果搭建，  
减少重复节点操作，提高角色展示与出片效率。

---

## 📌 当前版本特性

- 保留原始描边方案
- 新增可选修复描边按钮
- 一键创建二次元辉光节点
- 合成器自动切换为“总是”
- 辉光仅保留阈值控制，操作更简洁

---

## ⚠️ 说明

本插件当前主要面向二次元角色展示与风格化预览。  
不同模型结构、材质透明设置、法线状态可能会影响描边与辉光表现，  
如遇特殊模型效果异常，可优先尝试“修复描边”功能。
