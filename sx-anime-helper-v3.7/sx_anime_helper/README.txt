Paper朱二次元助手 V3.7（合并版）

合并自：
- 强化版 V3.1.0（Blender 5.0.1）：Matcap 高光皮肤、二分混合程度滑杆、单材质槽处理
- V2.0 风格色彩版：修复描边、全部撤销按钮、一键辉光（合成器 Bloom）、描边粗细/色彩曝光/辉光阈值实时调节

功能一览（3D 视图 → N 面板 → Paper二分）：

1. 一键添加描边
   - 应用 / 修复 / 撤销
   - 描边粗细滑杆，实时更新已应用的描边

2. 一键二次元色彩
   - 应用 / 撤销
   - 色彩对比预设（默认 Standard + 中高对比）与曝光调节

3. 一键添加高光皮肤
   - 应用（全部材质）/ 撤销
   - 二分混合程度、高光粗糙度滑杆，实时更新
   - 含 Matcap 质感叠加（matcap01.png）
   - 单材质槽处理：只处理选中的材质槽（自动跳过描边材质）

4. 一键二次元辉光
   - 应用 / 撤销
   - 辉光阈值滑杆，实时更新
   - 自动把 3D 视图合成器切到"总是"

5. 执行时自动切到 Eevee（可在面板底部关闭）

面板位置：
- 3D 视图 → N 面板 → Paper二分
- 着色器编辑器 → N 面板 → Paper二分（含单材质槽子面板）
- 材质属性 → Paper朱 高光皮肤材质

适配版本：Blender 4.1 - 5.x（辉光模块兼容 Blender 5 新合成器）

注意：皮肤与描边功能依赖 EEVEE（ShaderToRGB 节点），Cycles 下不可用。
